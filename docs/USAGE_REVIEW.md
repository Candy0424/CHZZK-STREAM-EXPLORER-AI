# 실사용 및 피드백 기록

## 실제 개발·사용 과정에서 확인한 내용

- 초기 화면에서는 샘플 방송인만 보여 실제 방송을 찾을 수 없었다는 사용자 피드백이 있었다. 공식 Client 인증과 PostgreSQL 수집을 연결한 뒤 실제 방송인·제목·시청자 수가 나타나는 것을 확인했다.
- 기존 색상이 마음에 들지 않는다는 요청을 받아 클라우드·미드나잇·라벤더·샌드·포레스트 5개 테마와 브라우저 저장 기능을 추가했다. 2026-09-15 실제 화면에서 라벤더 선택 상태를 확인했다.
- 2026-09-15 오전 실제 화면에서 카탈로그 6,154 / 온라인 827 / 오프라인 5,327을 확인했다. 같은 DB를 사용하는 MCP 도구도 09:27 KST에 같은 집계를 반환했다.
- 실제 화면에서 `아리사`를 검색하여 결과가 1개로 줄고, 해당 방송 제목과 공식 채널 링크가 표시되는 것을 확인했다. 즐겨찾기 버튼을 누르면 저장 수가 0에서 1로 바뀌고 버튼이 해제 상태로 전환되었다. 확인 후 원래대로 해제했다.

## 소감, 장단점과 개선점

처음에는 샘플만 나와 원하는 방송을 찾을 수 없었지만 실제 데이터를 연결한 뒤 검색과 상태 필터의 목적이 분명해졌다. 방송 제목과 시청자 수를 한 화면에서 비교할 수 있고, 원하는 테마를 고를 수 있어 기존 색상에 대한 불편도 줄었다.

장점은 여러 채널을 직접 열기 전에 방송 상태와 주제를 비교할 수 있다는 점이다. 이름 검색과 즐겨찾기는 자주 보는 방송을 찾는 과정을 줄여 준다. MCP에서도 같은 검색 결과를 활용할 수 있다.

한계는 수집 주기 때문에 방송 시작·종료가 즉시 반영되지는 않는다는 점이다. 오프라인 목록은 이전에 발견한 채널 범위이고, 즐겨찾기·테마는 현재 브라우저에만 저장된다. 다음 개선으로 알림, 기기 간 동기화, 실제 방송 상태와의 장기 비교를 고려한다.
