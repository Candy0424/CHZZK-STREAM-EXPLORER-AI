# API 장애를 오프라인으로 착각하지 않는 방송 탐색기 만들기

> 게시 전 초안입니다. 실제 API 실험·배포·실사용 결과를 보완한 뒤 사용자가 확인해 게시합니다. 현재 공개 게시물은 없습니다.

LiveScope는 치지직의 현재 라이브와 프로젝트에 등록한 채널을 함께 탐색하는 웹 앱이다. 라이브 목록 API가 현재 방송만 제공하기 때문에 모든 오프라인 계정을 열거할 수는 없다. 이전에 발견한 채널을 카탈로그로 유지하고, 최신 전체 수집에서 없어진 채널을 오프라인으로 처리했다.

가장 중요한 선택은 수집 도중에는 채널 상태를 변경하지 않는 것이다. 첫 페이지에 없다는 이유만으로 오프라인으로 처리하면 다음 페이지의 온라인 채널이 잘못 표시된다. 네트워크 오류로 일부 페이지만 수집한 경우도 마찬가지다. 모든 페이지를 임시 집합에 모은 뒤에만 DB 트랜잭션으로 새로운 상태를 확정했다.

Client 인증 정보는 서버에만 두었다. 웹 새로고침은 저장된 목록만 조회하고, 예약 작업이 원본 API를 호출한다. 중복 실행은 PostgreSQL 세션 잠금으로 막고, 429 응답은 재시도 가능한 시각을 저장해 불필요한 즉시 요청을 피한다.

화면은 어두운 배경과 연한 초록색으로 라이브 상태를 강조한다. 오프라인 카드에는 링크가 없고, 상태가 오래되면 지연을 표시한다. 검색·카테고리·태그 필터와 브라우저 즐겨찾기를 제공한다. 개발 미리보기 데이터는 실제 방송 정보와 명확히 구분했다.
